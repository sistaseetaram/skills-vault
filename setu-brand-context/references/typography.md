# Setu Typography — LOCKED

Three fonts. No more. No substitutions.

## Fonts

| Font | Role | Weights | Notes |
|---|---|---|---|
| **Cormorant Garamond** | Display, headings | 300–500 | Serif. Editorial feel. H1/H2/H3. |
| **Inter** | Body, UI | 400 (body), 500 (UI labels) | Body 17px / line-height 1.7. |
| **Noto Sans Devanagari** | `से` glyph in the Setu wordmark | — | Only used for the Sanskrit mark. Do not extend to other Latin text. |

## Label Spec

- 10px
- `text-transform: uppercase`
- `letter-spacing: 0.14em`
- Weight 500 (Inter)
- Use for eyebrow labels, micro-headings, section tags

## Body Spec

- Inter 400
- 17px base
- line-height 1.7
- Paragraph rhythm > visual density

## Heading Hierarchy

- Cormorant Garamond, lighter weights (300–400) for serenity
- Larger sizes carry the design — no shouting via weight
- No all-caps headings (reserved for the 10px label spec)

## Locked

- **No new fonts.** Not "just for this section." Not for variety.
- **No display font swaps.** Cormorant carries every heading.
- **No weight extremes.** 100/900 not in the system.
